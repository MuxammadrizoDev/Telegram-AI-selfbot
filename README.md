# Telegram-AI-selfbot
Telegram Selfbot that connects to your Telegram account and Gemini API key and responds for you whenever someone writes you(does not work in channels and groups) you can describe yourself so it will answer more questions, It can save messages if users ask to tell you something, you can check them in Saved messages(can work a little wrong).
To get it working create a file named .env (without dot it not gonna work and write API_ID, API_HASH and equal them to your account IP which you can get from (https://my.telegram.org/auth) it's official site so it's safe and also TELEGRAM_SESSION which is created when you confirm your number when you first run the bot and of course GEMINI_API_KEY write here your gemini api key which you get from (https://aistudio.google.com/api-keys) there is some codes for admins like /status to check status /on and /off to turn on/off and some others. You need to enter introduction about you in LANG_INSTRUCTIONS so LLM(AI) knows who you are. Good luck setting up selfbot.
